# One Piece Card Collection

Site de suivi de collection One Piece Card Game.

## Fonctionnalités actuelles
- Catalogue multilingue alimenté par l'index communautaire Punk Records.
- Recherche par nom ou numéro de carte.
- Filtres par langue, extension/deck, type et possession.
- Cases « Je possède » enregistrées dans le navigateur.
- Import et export de sauvegarde JSON.

## Mise en ligne gratuite
Le dépôt contient un workflow GitHub Actions dans `.github/workflows/deploy.yml`.
Dans GitHub : **Settings → Pages → Build and deployment → Source → GitHub Actions**. Ensuite, ouvre l'onglet **Actions** et vérifie que le déploiement se termine correctement.

Le catalogue dépend de la disponibilité et de la couverture de la source communautaire externe. L'exhaustivité des promos, variantes, sorties récentes et images doit encore être vérifiée. Les cases cochées sont stockées localement sur l'appareil et le navigateur utilisés ; exporte une sauvegarde pour les transférer.

Fan project non officiel. One Piece Card Game appartient à ses ayants droit.
