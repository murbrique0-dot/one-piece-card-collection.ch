Versions répertoriées

Le compteur en haut calcule toute ta collection répertoriée dans la langue choisie, même quand tu recherches ou filtres des cartes. Sur iPhone, ouvre ce site dans Safari, touche Partager puis « Sur l’écran d’accueil » pour l’installer. Sur Android, ouvre le menu Options puis « Installer l’application ». Si le bouton natif n’apparaît pas, ouvre le site dans Chrome et choisis ⋮ puis « Installer l’application » ou « Ajouter à l’écran d’accueil ». Les versions normales, parallèles et réimpressions sont affichées séparément lorsqu'elles figurent dans la base de données. Chaque version possède sa propre case. Les cartes DON!! restent de simples cartes à cocher. Les données sont issues de catalogues communautaires construits à partir des listes officielles ; les illustrations appartiennent à leurs ayants droit. Langues disponibles : français, anglais et japonais. La base ajoute aussi les designs DON!! (noms en anglais, sans choix de finition). Vérification des données : les index français et anglais contiennent respectivement 3 144 et 5 118 versions, chacune avec une URL d’image renseignée ; OP-18 en compte 152 dans chaque langue. Le catalogue japonais utilise Koala Kollect : 4 997 versions (2 822 normales, 1 714 parallèles et 461 réimpressions), toutes avec une URL d’image renseignée, jusqu’à OP-17. OP-18 japonais n’est pas encore présent dans cette source et reste à ajouter.
