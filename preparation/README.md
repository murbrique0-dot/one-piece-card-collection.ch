**Important :** rien dans ce dossier n'est chargé par le site GitHub Pages. Ne pas fusionner cette branche dans `main` tant que les cartes n'ont pas été collectées, vérifiées et approuvées.

- `EB-06/` — EAST BLUE

## Règles de préparation

1. Attendre les listes et images publiées par Bandai.
2. Utiliser la liste officielle Bandai comme référence des numéros, noms, couleurs, types et raretés.
3. Comparer les données françaises et anglaises avec Punk Records.
4. Ajouter les données japonaises uniquement après vérification d'une source japonaise à jour.
5. Contrôler les cartes de base, parallèles, SP, Treasure Rare, DON!! et réimpressions séparément.
6. Vérifier chaque identifiant, doublon et image.
7. Tester les liens Cardmarket avec le numéro de carte, sans ajouter de prix.
8. Ne jamais modifier les fiches existantes ni OP-18 dans le cadre de cette préparation.

Les fichiers `cards.json` restent vides jusqu'à la vérification des cartes.
